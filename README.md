# 💇‍♀️ LUMIÈRE — Sistema de Gestão de Salão de Beleza

Este repositório contém o projeto prático da disciplina de Análise e Projeto de Sistemas. O sistema foi desenvolvido para informatizar o agendamento e a gestão de um salão de beleza.

## 📖 Sobre o projeto
O site permite que clientes agendem horários online sem precisar de login (usando apenas o telefone), com validação de regras de negócio como limite de agendamentos e consentimento da LGPD. A equipe do salão (recepcionistas e profissionais) acessa uma área restrita para gerenciar a agenda.

## 🛠️ Tecnologias Utilizadas
* **Node.js** e **Express** (Servidor backend)
* **HTML5** e **CSS3** (Estrutura e estilização)
* **JavaScript** (Lógica de agendamento, validações e painel da equipe)
* **Git** e **GitHub** (Versionamento de código)
